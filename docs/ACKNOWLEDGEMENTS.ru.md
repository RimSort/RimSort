# Благодарности

RimSort создан oceancabbage. Разработка возможна только благодаря людям, которые делятся работой и опытом. Здесь перечислены авторы и проекты, чьи инструменты и идеи помогли RimSort.

* **[joseasoler](https://github.com/joseasoler)** — [todds](https://github.com/todds-encoder/todds), оптимизация текстур в `.dds` в RimSort
* **[Paladin и RimPy](https://github.com/rimpy-custom/RimPy)** — RimSort создан как community-oriented FLOSS-альтернатива RimPy
* **[SteamworksPy](https://github.com/philippj/SteamworksPy)** — API Steamworks для клиента Steam и DB Builder (Steam DB)
* **Всё сообщество!** — без вас это не имело бы смысла. Заходите в [Discord](https://discord.gg/aV7g69JmR2)
