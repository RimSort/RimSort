# Базовое использование

## Первоначальная настройка

При первом запуске укажите пути к игре и конфигурации, при необходимости установите SteamCMD.

## Главное окно

- **Панель информации о моде** — слева
- **Активные / неактивные моды** — списки с drag-and-drop
- **Меню** — импорт/экспорт списков, браузер мастерской, todds, настройки

## Минимальные настройки

В **Settings → Locations** задайте:

- Папку установки RimWorld
- Папку конфигурации (ModsConfig.xml)
- Папку локальных модов

## Импорт списка модов

- **File → Open mod list** — RimWorld XML / `.rml` / `.rws` и JSON-экспорт RimSort
- **Troubleshooting → Import** — запись в `ModsConfig.xml` (XML и JSON)

## Сортировка и сохранение

Кнопка **Sort** упорядочивает активные моды. **Save** записывает `ModsConfig.xml`.

## Внешние базы данных

Релизы не включают Steam DB и Community Rules — их нужно скачать или собрать. См. [базы данных](/ru/user-guide/databases).
