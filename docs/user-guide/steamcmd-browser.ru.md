# SteamCMD и браузер мастерской

{: .no_toc}

[SteamCMD][SteamCMD] — утилита Valve, которую RimSort опционально интегрирует для скачивания модов Steam Workshop без Steam и без копии RimWorld в Steam. Встроенный браузер мастерской позволяет просматривать Steam Workshop напрямую и выбирать моды для загрузки через SteamCMD.

RimSort поддерживает обновление модов, установленных через SteamCMD, — вы получаете более точный контроль над тем, когда обновлять моды Workshop, по сравнению с прямым использованием Steam.

## Настройка SteamCMD

В Linux RimSort хранит пользовательскую конфигурацию SteamCMD в отдельном `home` внутри настроенного префикса SteamCMD. Это предотвращает изменение SteamCMD конфигурации библиотек настольного Steam-клиента.

## Использование браузера мастерской

Браузер мастерской — встроенное web-представление Steam Community, которое позволяет просматривать мастерскую RimWorld и ставить моды в очередь на загрузку, не покидая RimSort. Боковая панель (**Mod Downloader**) содержит список выбранных модов.

Чтобы добавить мод:

1. Перейдите на страницу мода или коллекции. Когда активная страница — страница мода или коллекции, в навигационной панели появляется кнопка **Add to list**.
2. Нажмите **Add to list**, чтобы добавить мод в список загрузки. Можно также нажать **Add Mods by Workshop ID**, чтобы вставить один или несколько Steam published file ID напрямую.

Каждая запись в списке загрузки показывает значок состояния:

- **Default** — мод в списке, но ещё не скачан. Для этого состояния показывается элемент **Add to list**.
- **Added** — мод выбран и стоит в очереди. Состояние отмечается значком `-`.
- **Installed** — мод уже присутствует в наборе активных модов. Состояние отмечается значком `✓`.

ПКМ по записи — удалить её по отдельности; двойной клик — открыть страницу мода в мастерской; **Clear List** — очистить очередь.

Когда список готов, выберите способ загрузки:

- **Download mod(s) (SteamCMD)** — загрузка через SteamCMD. Не требует Steam-клиента или копии RimWorld в Steam; предпочтительный способ для offline/SteamCMD-инстансов.
- **Download mod(s) (Steam app)** — подписка через Steam-клиент (Steamworks API). Требует запущенного и авторизованного Steam-клиента и наличия RimWorld в Steam. Используйте, если хотите, чтобы модами также управляла ваша библиотека Steam.

{: .note}
> Пока включено просмотрение, RimSort скрывает нативные кнопки Steam «Subscribe», чтобы вся загрузка шла через два описанных выше способа.

## Обновление SteamCMD модов

RimSort отслеживает моды, скачанные через SteamCMD, по файлу `appworkshop_294100.acf` в префиксе SteamCMD. Чтобы проверить обновления, используйте `Download > Update Workshop Mods`, либо включите *Check for mod updates on refresh* в *Settings → Advanced*, чтобы проверка выполнялась автоматически при каждом обновлении списка модов.

При проверке RimSort сравнивает временные метки обновления установленных SteamCMD-модов (значение `timeupdated` в файле `.acf` и время модификации папки мода) с актуальными метками из Steam WebAPI. Устаревшие моды появляются в панели *Workshop Mod Updater*, где их можно скачать заново через SteamCMD или снова подписаться через Steam-клиент (Steamworks API).

Если вы предпочитаете при каждом обновлении заменять мод чистой копией, включите **Delete before update** в *Settings → Internal Tools → SteamCMD*. Это удалит существующую папку мода перед повторной загрузкой. Учтите: поскольку RimSort опирается на файл `.acf` для определения обновлений, очистка `.acf` может помешать проверкам обновлений — см. [Устранение неполадок](#устранение-неполадок) ниже.

## Логи SteamCMD

{: .important}
> SteamCMD, будучи внешним инструментом, имеет собственный набор логов. Вы найдёте их в установочной папке SteamCMD, которая зависит от настройки вашего экземпляра RimSort.
>
> Текущую установочную папку SteamCMD можно посмотреть в настройках: `SteamCMD > SteamCMD installation location`. Логи находятся в подпапке `logs` папки SteamCMD.

## Устранение неполадок

Иногда SteamCMD может вести себя нежелательно: сбои загрузки, повторная установка удалённых модов и т.п. Если проблема не связана с сетью (ваш компьютер не может связаться с серверами Valve), попробуйте следующее.

- Очистите кэш depotcache SteamCMD
- Очистите файл `.acf`

Обе операции можно выполнить вручную или через RimSort на странице настроек `Internal Tools > SteamCMD`.

{: .warning}
> RimSort при проверке обновлений SteamCMD-модов полагается на данные в файле `.acf`. Удаление и/или очистка файла `.acf` может вызвать проблемы с обновлением SteamCMD-модов.
