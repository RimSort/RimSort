# 致谢

RimSort 由 oceancabbage 创建。RimSort 的发展离不开那些愿意分享自己的工作成果与专业知识的人们。本文件列出了对 RimSort 有所助益的个人或团体。

* **[joseasoler](https://github.com/joseasoler)** — 感谢 [todds](https://github.com/todds-encoder/todds)，它使 RimSort 中的 `.dds` 纹理优化成为可能
* **[Paladin 以及他为 RimPy 所做的努力](https://github.com/rimpy-custom/RimPy)** — 如果你接触 RimWorld 模组圈子有一段时间，你多半至少听说过 RimPy。RimSort 旨在成为面向社区、完全 FLOSS（自由开源）的 RimPy 及其相关工作流的替代方案。
* **[SteamworksPy](https://github.com/philippj/SteamworksPy)** — Steamworks API 是我们与 Steam 客户端交互的基础。应用以及通过 DB Builder 构建 SteamDB 都会用到它。这个 Python 模块为许多功能提供了可能。
* **全体社区！** — 正是因为你们，这一切才成为可能，所以请继续制作出色的模组并支持这款游戏！欢迎加入我们的 [Discord](https://discord.gg/aV7g69JmR2)！
